# Savana – Wardrobe Match AI

Wardrobe Match AI is a redesigned feature for the Savana Dresses application. It helps users find clothes that match items they already own.

### Key Features
- Upload a clothing image.
- Select clothing category and colour.
- Choose an occasion and budget.
- View sample matching products.
- Save favourite products to a shortlist.

### Technologies
HTML, CSS and JavaScript.

### How to Run
Open `index.html` in any web browser.

### Note
This is an interactive HCI prototype. It uses manual clothing selections and sample product recommendations; real AI integration is planned for future development.
